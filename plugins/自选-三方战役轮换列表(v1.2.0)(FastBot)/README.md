# 三方战役轮换列表

当前版本：`1.2.0`。

管理员使用 `!clist` 管理一次性的三方战役待播放清单。插件从游戏 Mission
数据中读取 `builtin=0` 的战役，只展示大图，不展示小关。

## 功能

- 生成或重置当前已安装的三方战役清单。
- 查看清单并立即开始所选战役、移到最前、移到队尾或从本轮删除。
- 确认清单后立即切换到队首首章，或等待当前战役结束后切换。
- 在三方图游玩中立即跳过当前战役并进入下一张。
- 当前战役与当前小关单独持久化；服务器或游戏进程崩溃后重新载入同一关时继续当前战役，不会误消费下一张。
- 进入下一张战役后才结算上一张；管理员手动跳过仍会立即把当前战役标记为已处理。
- 周期性在聊天栏提醒下一张三方战役。
- 管理员可暂停轮换，并手动继续未完成的三方战役。
- 确认服务器持续一段时间没有真人后自动暂停并记录当前小关；默认等待 30 秒，正在连接或载入的真人同样计为在线，避免换图期间误暂停。真人回来后仍需管理员手动继续。
- 暂停时清除三方图的下一图覆盖，让自动换图插件恢复默认官图逻辑。

## 权限与指令

- `sm_clist` / `!clist`：需要 SourceMod 换图权限 `f`。

## 依赖

- `map_changer` 1.0.7 或更高版本：提供设置和清除下一图接口，并兼容非标准终局的事件顺序。
- `l4d2_source_keyvalues`：读取游戏内部 Mission 数据。

## 配置

首次运行生成 `cfg/sourcemod/l4d2_custom_campaign_list.cfg`：

```text
// 下一张战役聊天提醒间隔（秒），0 关闭
clist_ad_interval "300"

// 服务器无真人后确认暂停轮换的等待时间（秒），范围 5-300
clist_empty_confirm_delay "30"
```

待播放清单保存在 `addons/sourcemod/data/l4d2_custom_campaign_list.cfg`。
`Current` 保存正在进行的战役、当前小关和终局完成状态，`Pending` 只保存后续战役。
旧版状态文件会在识别出当前三方图后自动迁移。
重新生成会覆盖原顺序，并恢复本轮已删除或已经玩过的战役。
